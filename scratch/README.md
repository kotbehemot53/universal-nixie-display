Scratch
=======

Experiments and throwaway work that is not part of the product but is worth keeping around.

- `kicad-experiments/` - old KiCad experiments (`xprmnt1`, `xprmnt2`), imported from the gitignored
  `kicad/xprmnt` directory of the previous hardware repo. `xprmnt2` references DigiKey libraries from a
  machine-local path in its library tables; the symbols and footprints are embedded so it still opens.
